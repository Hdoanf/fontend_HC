Install on Android

1. Download the APK Use the download button on this page to fetch the latest release package.
2. Allow install from browser or file manager If Android blocks installation, enable the permission for unknown apps in system settings.
3. Open and install Tap the downloaded file, confirm install, then launch Smart Home HC from your app drawer.
